How to Fix Node.js PATH Errors on Windows

This guide will help you resolve errors where "node" is not recognized as an executable command.

Step 1: Check if Node.js is already installed
1. Press the Windows key + R to open the Run dialog.
2. Type cmd and press Enter to open the Command Prompt.
3. Type node -v and press Enter.
   - If you see a version number (e.g., v18.16.0), Node.js is installed, but it's not in your PATH. Proceed to Step 3.
   - If you see an error like "'node' is not recognized...", Node.js is likely not installed. Proceed to Step 2.

Step 2: Install Node.js (if not installed)
1. Go to the official Node.js website: https://nodejs.org/
2. Download the LTS (Long Term Support) version for Windows.
3. Run the downloaded installer.
4. Keep clicking "Next" through the installation process.
5. CRITICAL: When you reach the "Custom Setup" screen, ensure that the "Add to PATH" feature is selected to be installed on your local hard drive (it usually is by default).
6. Finish the installation.
7. Restart your Antigravity IDE for the changes to take effect.

Step 3: Add Node.js to your PATH manually
(Only needed if Node.js is installed but still not working)
1. Press the Windows key, type env, and select "Edit the system environment variables".
2. In the System Properties window, click the "Environment Variables..." button at the bottom right.
3. In the "System variables" section (the bottom half), scroll down and find the variable named Path. Select it and click "Edit...".
4. Click "New" and type in the path to your Node.js installation directory. The default path is usually C:\Program Files\nodejs\
5. Click "OK" on all three windows to save your changes.
6. Restart your Antigravity IDE so it can detect the newly added PATH.
