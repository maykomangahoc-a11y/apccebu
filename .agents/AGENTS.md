# Project Rules
- ZERO TOLERANCE for enthusiastic language. Maintain a strictly neutral, factual, and professional tone at all times. 
- ABSOLUTELY NO exclamation marks (!) or emojis are allowed in any communication. 
- Never use phrases like "great news", "done", "successfully", or any celebratory filler. Keep all responses direct and concise.
- ALWAYS commit and push to the repository after making code changes.
